# Magic Motion（魔法手势）

# 技能系统详细规格文档 V1.0

## 文档目的

本文档定义 Magic Motion MVP 的技能系统设计。

目标：

-   固化技能生成规则；
-   定义技能识别逻辑；
-   指导 Unity Skill Engine 开发；
-   支撑后续技能扩展。

------------------------------------------------------------------------

# 一、技能系统定位

Magic Motion 不采用传统按钮技能模式。

传统游戏：

点击技能按钮 → 释放技能。

Magic Motion：

玩家动作 → AI理解 → 技能生成 → 魔法反馈。

核心理念：

> 技能是一种由人体动作组成的魔法语言。

------------------------------------------------------------------------

# 二、技能生成模型

    状态

# 三、技能输入参数

## 3.1 基础手型 Gesture

来源：

手部关键点识别。

例如：

-   OPEN_PALM 张掌
-   FIST 握拳
-   FIVE_FINGER_PALM 并指掌
-   CLAW 爪型
-   LOTUS 莲花指
-   METAL 金属礼型
-   LOVE Love型

------------------------------------------------------------------------

## 3.2 掌心方向 Palm Direction

支持：

-   向前
-   向后
-   朝摄像头
-   左侧
-   右侧

用途：

区分相同手型产生的不同技能。

------------------------------------------------------------------------

## 3.3 动作 Motion

支持：

### 方向动作

-   X轴左右
-   Y轴上下
-   Z轴前后

### 动作类型

-   PUSH 推出
-   PULL 收回
-   HOLD 保持
-   MOVE_CLOSE 靠近
-   MOVE_AWAY 分离
-   ROTATE 旋转

------------------------------------------------------------------------

## 3.4 轨迹 Trajectory

支持：

-   直线
-   圆形
-   S形
-   V形

------------------------------------------------------------------------

## 3.5 时间条件 Duration

技能可以定义：

-   完成时间
-   蓄力时间
-   持续时间

例如：

5秒内没有完成：

施法失败。

# 七、MVP技能定义

# SK001 震山掌

## 类型

爆发攻击。

## 定位

近距离力量型技能。

## 触发条件

    张掌

    +

    掌心向前

    +

    快速推掌

## 识别条件

-   手型置信度达标；
-   掌心方向正确；
-   Z轴快速移动；
-   在时间窗口内完成。

## 技能流程

    准备

    ↓

    聚气

    ↓

    推掌

    ↓

    掌印生成

    ↓

    冲击波

    ↓

    敌人击退

## 效果

-   手部能量
-   金色掌印
-   冲击波
-   击退反馈

------------------------------------------------------------------------

# SK002 火球术

## 类型

远程攻击。

## 设计调整

原方案：

炎火法阵。

调整为：

火球术。

原因：

-   MVP表现更直接；
-   技术实现更简单；
-   玩家更容易理解。

## 触发条件

    并指掌

    +

    前送释放

## 技能流程

    掌心聚火

    ↓

    目标锁定

    ↓

    火球生成

    ↓

    飞行

    ↓

    命中爆炸

## 技术需求

包含：

-   Target Lock
-   Projectile System
-   Impact System

------------------------------------------------------------------------

# SK003 护体金光

## 类型

持续防御技能。

## 设计目的

    +
    快速推掌

    张掌
    +
    掌心朝摄像头
    +
    保持

## 技能流程

    掌心展开

    ↓

    符文出现

    ↓

    护盾形成

    ↓

    持续防御

## 取消方式

-   握拳；
-   手自然下垂；
-   状态丢失。

## 防御逻辑

攻击：

↓

护盾检测

↓

吸收伤害

↓

护盾值减少

------------------------------------------------------------------------

# 十一、开发要求

1.  技能必须配置化。
2.  禁止每个技能单独硬编码。
3.  所有技能共享状态机。
4.  新增技能只增加配置和资源。
5.  保留未来技能编辑能力。
