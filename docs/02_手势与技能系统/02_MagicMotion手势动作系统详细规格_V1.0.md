# Magic Motion 手势动作系统详细规格 V1.0

# 一、核心定义

技能由：

基础手型 + 掌心方向 + 空间动作 + 时间条件 + 轨迹

组合产生。

------------------------------------------------------------------------

# 二、手型库

## G001 握拳

定义： 五指收拢。

用途： 取消技能、力量型动作。

------------------------------------------------------------------------

## G002 张掌

定义： 五指自然展开。

用途： 防御、释放基础能量。

------------------------------------------------------------------------

## G003 爪型

定义： 五指展开并向内弯曲。

用途： 抓取、召唤。

------------------------------------------------------------------------

## G004 莲花指

定义： 拇指、中指并拢。

其他手指展开。

用途： 辅助、召唤、控制。

------------------------------------------------------------------------

## G005 金属礼型

定义： 拇指、中指、无名指并拢。

食指、小指展开。

用途： 特殊魔法。

------------------------------------------------------------------------

## G006 Love型

定义： 中指、无名指并拢。

拇指、食指、小指展开。

用途： 特殊交互。

------------------------------------------------------------------------

## G007 并指掌

定义： 五指伸直并拢。

用途： 基础施法。

------------------------------------------------------------------------

# 三、动作库

## 空间方向

X轴： 左右。

Y轴： 上下。

Z轴： 前后。

------------------------------------------------------------------------

## 轨迹

支持：

-   圆
-   S
-   V

------------------------------------------------------------------------

## 状态动作

支持：

-   快速释放
-   缓慢移动
-   保持
-   持续引导

------------------------------------------------------------------------

# 四、识别条件

每个技能需要：

手型置信度

-   动作完成度

-   时间窗口

-   方向判断

------------------------------------------------------------------------

# 五、取消规则

统一支持：

-   超时取消；
-   手自然下垂取消；
-   姿态丢失取消。
