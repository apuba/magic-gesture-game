# 一、项目概述

## 1.1 项目名称

Magic Motion（魔法手势）

------------------------------------------------------------------------

## 1.2 项目定位

Magic Motion 是一款基于 AI 视觉识别与体感交互技术的魔法战斗游戏。

玩家无需传统按钮操作，通过摄像头识别自己的双手动作，将：

-   手势
-   姿态
-   空间移动
-   动作轨迹
-   持续状态

转换为游戏中的魔法技能。

------------------------------------------------------------------------

## 2.1 初始方向

最初方向：

"手势驱动的魔法体验"。

用户不是点击技能，而是在施法。

# 十、技能冲突解决原则

不同技能不能只依靠同一个手势。

必须加入：

-   方向
-   动作
-   时间
-   持续状态

例如：

震山掌：

张掌 + 推掌

护盾：

张掌 + 保持
