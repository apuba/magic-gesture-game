# Magic Motion 项目沟通演进档案 V1.0

## 文档目的

记录项目从最初想法到MVP确定过程中的关键决策。

本文件不是简单总结，而是记录： - 为什么提出某方案； - 为什么调整； -
最终形成什么设计。

------------------------------------------------------------------------

# 第一阶段：项目起源

## 初始方向

项目最初为隔空手势控制应用。

目标： 通过摄像头识别人手动作，实现人与设备之间的自然交互。

------------------------------------------------------------------------

# 第二阶段：产品方向转型

经过讨论，项目从工具型应用转向：

"手势驱动魔法体验"。

核心变化：

不是： 用户控制手机。

而是： 用户通过自己的动作创造魔法。

------------------------------------------------------------------------

# 第三阶段：虚拟双手设计

确定需要虚拟双手表现。

原因：

如果只有技能特效： 用户感觉是在点击按钮。

如果显示自己的虚拟手： 用户感觉魔法来自自己的动作。

------------------------------------------------------------------------

# 第四阶段：MVP范围确定

确定先做固定靶场Demo。

目的：

验证核心闭环：

摄像头 → 识别动作 → 释放技能 → 击中目标 → 反馈

------------------------------------------------------------------------

# 第五阶段：技能语言系统形成

确定技能不是按钮。

技能由：

手型 + 动作 + 空间变化 + 时间条件

组成。

形成Magic Motion核心玩法。

------------------------------------------------------------------------

# 第六阶段：持续技能概念形成

确定部分技能需要持续存在。

例如：

护盾： 保持动作则持续。

聚灵： 持续引导。

形成： 技能状态机。

------------------------------------------------------------------------

# 第七阶段：最终MVP方向

最终目标：

实现玩家第一次体验：

看到摄像头识别自己动作， 通过双手释放魔法， 完成一次战斗。
