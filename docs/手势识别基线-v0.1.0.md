## 冻结规则

1. 后续识别、阈值、坐标变换和帧率修改不得直接覆盖本基线。
2. 任何修改必须记录：修改原因、改动参数、旧值/新值、测试设备、正例/负例结果和回归结论。
3. 若修改影响识别行为，应创建新的版本 tag；未通过对比验证前，不更新“稳定基线”描述。
4. 玩法、UI、音效和特效开发可以在不改变识别输入输出契约的前提下继续进行。
5. 新增识别能力优先通过独立回放或新增测试覆盖，不以单次真机体感替代基线对比。
