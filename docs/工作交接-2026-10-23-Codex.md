## 4. 关键设计约定（务必遵循，否则会重新引入方向 bug 或遮挡 bug）

- **一切距离、角度、比例都必须基于「平方距离」**：归一化坐标非正方形，原始距离/角度随手机朝向变化。新增测量直接用 `HandGeometry.SquareDistance` / `SquareDirection`，并传入 `widthToHeight`。
- **`widthToHeight` 透传链不能断**：`MediaPipe 帧 → HandTrackingResult.WidthToHeight → VisionPipeline 发布 → GestureRecognizer / BasicGestureClassifier / GestureDataRecorder / HandTrackingDebugView`。任何新消费方从 `HandTrackingResult` 取这个值，不要硬编码 16/9。
- **两套翻转定义必须一致**：`GetDisplayUv`（摄像头贴图翻转）与 `LandmarkToGuiNormalized`（骨架点映射）复用同一套「先两翻后旋转」逻辑，否则骨架与画面错位。
- **识别坐标与显示坐标分离**（符箓系统）：方向判定取掌心、绘制取指尖/掌前锚点；方向在屏幕坐标下做（`-y` 为向上），保证「上」始终是玩家眼中的上。
- **IMGUI 绘制顺序**：`RuneFollowView.OnGUI` 必须在开头一次性 `GUI.depth = -99`，中途改 depth 不生效。
- **开发期日志用 `#if DEVELOPMENT_BUILD || UNITY_EDITOR` 守卫**，避免发布构建携带诊断输出。
- **`OverlaySettings` 持久化用 PlayerPrefs**：新增开关必须带版本号迁移（参考 `KeyTrackingRateVersion`）。

### 6.2 真机安装（HONOR ALP-AN00，`AXYP6R4A30002818`）

> **已知坑：5037 端口冲突。** 本机默认 adb 端口 5037 会被一个**非 adb 进程间歇性占用**，导致 `adb server version (19045) doesn't match this client (41)` 或 `cannot connect to daemon at tcp:5037`。`netstat` 看 5037 只有 `TIME_WAIT`、无 `LISTENING`，所以不是常驻 adb 进程，而是偶发抢占。
> **解决办法：让本机 adb 改用 5038 端口常驻**（所有 adb 命令前先设该环境变量）：

```powershell
$env:ANDROID_ADB_SERVER_PORT="5038"
D:\Android\Sdk\platform-tools\adb.exe start-server
D:\Android\Sdk\platform-tools\adb.exe devices
D:\Android\Sdk\platform-tools\adb.exe -s AXYP6R4A30002818 install -r -d E:\2026\MagicMotion\Builds\Android\MagicMotion-Development.apk
```

- adb 路径：`D:\Android\Sdk\platform-tools\adb.exe`
- 设备 USB 序列号：`AXYP6R4A30002818`（HONOR ALP-AN00）
- 参数 `-r`（覆盖）`-d`（允许同版重装）
- **校验 APK 用 SHA-256，不要只看文件名**（见符箓跟随交接文档各轮构建日志的 SHA-256）。

### 6.3 无线调试（USB 不稳时的备选）

手机开启「设置 → 开发者选项 → 无线调试」，记下 IP:端口（如 `192.168.31.251:38917`）：

```powershell
$env:ANDROID_ADB_SERVER_PORT="5038"
D:\Android\Sdk\platform-tools\adb.exe connect 192.168.31.251:38917
D:\Android\Sdk\platform-tools\adb.exe -s 192.168.31.251:38917 install -r -d E:\2026\MagicMotion\Builds\Android\MagicMotion-Development.apk
```

- 若需要先配对：进入「使用配对码配对设备」拿到**新的** IP:端口 + 6 位配对码（**每次打开都重新生成、有效期很短**），立刻 `echo <码> | adb pair <IP>:<配对端口>`。配对码过期会 `Wrong password`。
