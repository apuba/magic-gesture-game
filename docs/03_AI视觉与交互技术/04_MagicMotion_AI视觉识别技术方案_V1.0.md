# Magic Motion AI视觉识别技术方案 V1.0

## 目标

通过手机摄像头理解玩家双手动作，将人体动作转换为技能输入。

## 技术链路

摄像头 → 图像采集 → Hand Tracking → 21关键点 → 手型识别 → 动作分析 →
技能匹配

## 手部数据

每只手包含：

-   左右手标识
-   21个Landmark坐标
-   置信度
-   掌心方向
-   手指状态

## 手型识别

通过：

-   指尖位置
-   指节角度
-   手指伸展程度
-   指尖距离

判断：

握拳、张掌、并指掌、莲花指等。

## 动作识别

支持：

-   X/Y/Z轴移动
-   推掌
-   拉回
-   保持
-   双手靠近

## 防误触

采用：

-   置信度阈值
-   连续帧确认
-   时间窗口
-   动作完成度判断

## Unity接口

输出：

GestureDetected

MotionDetected

SkillTrigger
