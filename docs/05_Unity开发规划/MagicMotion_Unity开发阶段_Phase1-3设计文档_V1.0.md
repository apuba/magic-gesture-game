# 五、手型识别规则

## FIST 握拳

条件：

五指收拢。

指尖接近掌心。

------------------------------------------------------------------------

## OPEN_PALM 张掌

条件：

五指伸直展开。

------------------------------------------------------------------------

## CLAW 爪型

条件：

五指展开。

同时指关节弯曲。

------------------------------------------------------------------------

## LOTUS 莲花指

定义：

拇指、中指并拢。

食指、无名指、小指展开。

识别：

    ThumbTip

    接近

    MiddleTip

------------------------------------------------------------------------

## METAL 金属礼型

定义：

拇指、中指、无名指并拢。

食指、小指展开。

------------------------------------------------------------------------

## LOVE型

定义：

中指、无名指并拢。

拇指、食指、小指展开。

------------------------------------------------------------------------

## FIVE_FINGER_PALM 并指掌

定义：

五指伸直并拢。

区别：

张掌：

五指距离大。

并指掌：

五指距离小。

------------------------------------------------------------------------
